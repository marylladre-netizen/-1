ЕЖЕДНЕВНИК — переработанная тестовая версия по вашему макету.

Визуально:
- тёмно-зелёный фон, белая надпись;
- крупный рукописный заголовок «Ежедневник»;
- тонкий каллиграфический шрифт Bodoni Moda и Great Vibes;
- верхняя ветвь с заснеженными красными ягодами;
- дата с тонкими декоративными линиями;
- большая стеклянная плашка прогресса с заливкой по проценту;
- свободная компоновка задач с круглыми чекбоксами;
- нижняя орнаментальная линия и три значка: главная, календарь, прогресс;
- переключатель белой темы с красным текстом.

Задачи и подзадачи сохраняются локально в браузере.
Для добавления на экран «Домой» разместите файлы на HTTPS-хостинге и откройте index.html в Safari.
Шрифт загружается из Google Fonts; для первого отображения шрифта нужен интернет.
